## 关键目录说明

### 允许修改的目录（本人二次开发范围）

| 目录 | 用途 | 修改内容 |
|------|------|----------|
| `theme/oss-blog-theme/` | 自定义主题源码 | 收藏功能 JS/CSS、模板修改、导航扩展 |
| `runtime/content/themes/source/` | 实际生效主题（已集成收藏功能） | default.hbs、post.hbs、page.hbs、navigation.hbs 修改 |
| `docs/` | 项目文档 | 基线、架构、测试、实验报告 |
| `tests/` | 测试用例与记录 | 功能测试、权限测试、界面测试、恢复测试 |
| `scripts/` | 辅助脚本 | 启动/停止脚本、数据导出脚本 |

### 禁止修改的目录（Ghost 核心，不重写基础能力）

| 目录 | 用途 | 不修改原因 |
|------|------|------------|
| `runtime/node_modules/ghost/` | Ghost 核心代码 | 升级边界，修改核心会导致无法升级 |
| `runtime/core/` | Ghost 核心服务 | 认证、内容、会员、评论等基础能力由上游提供 |
| `runtime/content/data/` | SQLite 数据库文件 | 运行时数据，不提交到 Git |
| `runtime/content/logs/` | 日志文件 | 运行时产生，不提交到 Git |

## 请求路径分析

### 前台文章浏览请求路径
```
浏览器 → Ghost HTTP 服务器 → 主题层 (Handlebars 模板渲染)
→ Content API (查询文章/标签/作者数据)
→ SQLite 数据库 (读取内容)
→ 返回渲染后的 HTML
```

### 收藏功能请求路径（自主扩展）
```
浏览器 → 主题层 bookmark.js (前端逻辑)
→ localStorage (本地存储，无需后端)
→ 收藏列表渲染 (前端模板)
```

**设计决策**：收藏功能选择在主题层实现，使用 localStorage 本地存储，而不是修改 Ghost 核心。原因：
1. 不破坏升级边界，Ghost 核心升级不影响收藏功能
2. 无需后端 API 开发，减少复杂度
3. 数据存储在用户浏览器，隐私友好
4. 符合实验"修改主题或伴随服务，不修改核心"的要求

### 管理后台请求路径
```
浏览器 → Ghost Admin (Ember.js SPA)
→ Admin API (认证/内容管理/设置)
→ Ghost 核心服务 (业务逻辑)
→ SQLite 数据库 (读写)
```

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端主题 | Handlebars + CSS + 原生 JS | Ghost 主题模板，收藏功能用原生 JS 实现 |
| 后端服务 | Node.js + Express | Ghost 核心，不修改 |
| 数据库 | SQLite | 本地开发环境，随 Ghost 安装 |
| 管理后台 | Ember.js | Ghost Admin，不修改 |
| 版本管理 | Git | 个人实验仓库 |

## 数据流

### 内容数据流
```
管理员 (Ghost Admin) → Admin API → Ghost 核心 → SQLite
                                                ↓
访客/会员 (浏览器) ← 主题渲染 ← Content API ← SQLite
```

### 收藏数据流（自主扩展）
```
用户点击收藏按钮 → bookmark.js 读取文章元数据
→ 写入 localStorage (oss_blog_bookmarks)
→ 更新导航栏角标计数
→ 收藏列表页读取 localStorage → 渲染列表
```

## 安全边界

- 管理密钥、数据库口令不提交到 Git，通过 `.gitignore` 排除
- 收藏功能纯前端实现，不接触后端敏感数据
- 会员评论权限由 Ghost 核心管理，不绕过
- 内容导出文件脱敏，不包含真实用户隐私
