## 导出方法

### 方法一：通过管理后台导出 JSON（推荐）

1. 登录管理后台 http://localhost:2368/ghost/
2. 进入 设置（Settings）→ 实验室（Labs）
3. 在"迁移工具"（Migration tools）部分点击"Open"
4. 切换到"Export"标签页
5. 点击"Export"按钮，下载 JSON 文件
6. 将下载的文件保存到 `docs/export/` 目录

导出的 JSON 文件包含：
- 所有文章（含草稿和已发布）
- 所有标签
- 所有页面
- 会员信息（密码为哈希值，非明文）
- 评论
- 站点设置

### 方法二：直接备份 SQLite 数据库（已完成）

Ghost 开发环境使用 SQLite 数据库，文件位于：
```
runtime/content/data/ghost-dev.db
```

直接复制该文件即可完成完整备份。本实验已备份至：
```
docs/export/ghost-dev-backup-2026-09-07.db
```

## 恢复方法

### 方法一：通过管理后台导入 JSON

1. 全新安装 Ghost（同版本 v6.62.0）
2. 完成管理员初始化
3. 进入 设置 → 实验室 → 迁移工具 → Import
4. 选择导出的 JSON 文件
5. 等待导入完成
6. 验证文章、标签、页面是否正确导入
7. 重新安装并激活自定义主题

### 方法二：恢复 SQLite 数据库文件

1. 停止 Ghost：`ghost stop`
2. 将备份的数据库文件复制到 `runtime/content/data/ghost-dev.db`（覆盖）
3. 启动 Ghost：`ghost start`
4. 验证所有数据是否正常

## 数据脱敏说明

- 导出文件中的会员密码为 bcrypt 哈希值，非明文密码
- 不包含管理员密码（管理员密码在数据库中也是哈希存储）
- 不包含 API 密钥（需在管理后台重新生成）
- 提交到 Git 前已确认无敏感明文信息
