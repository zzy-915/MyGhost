## PR 描述

### 解决的问题

作为博客读者，浏览文章时经常遇到"这篇文章很有用但现在没时间读"的场景，关闭后很难再找到。需要一个一键收藏、稍后阅读的功能。

### 实现方案

在 Ghost 主题层实现收藏功能，使用浏览器 localStorage 本地存储，不修改 Ghost 核心代码。

### 主要变更

| 类型 | 文件 | 说明 |
|------|------|------|
| 新增 | assets/js/bookmark.js | 收藏功能核心逻辑（约250行） |
| 新增 | assets/css/bookmark.css | 收藏功能样式（约150行） |
| 新增 | page-bookmarks.hbs | 收藏列表页模板 |
| 修改 | default.hbs | 引入 CSS/JS，导航栏收藏入口 |
| 修改 | post.hbs | 文章详情页收藏按钮 |
| 修改 | page.hbs | 收藏页面内容渲染 |
| 修改 | partials/components/navigation.hbs | 导航栏收藏链接 |
