## 用户故事

作为博客读者，我希望通过中文关键词搜索到相关文章，在无结果时看到友好提示，以便快速找到感兴趣的内容。

## 需求描述

1. 使用 Ghost 原生搜索功能
2. 验证中文关键词命中标题或正文
3. 验证无结果时给出明确提示
4. 验证搜索结果可跳转
5. 验证匿名用户可搜索公开文章

## 验收条件

- [x] 搜索"JavaScript"能命中《深入理解JavaScript闭包与作用域链》
- [x] 搜索"Docker"能命中《Docker容器化部署最佳实践》
- [x] 搜索"不存在的关键词xyz123"显示无结果提示
- [x] 点击搜索结果可跳转到文章详情页
- [x] 未登录状态下可正常搜索公开文章

## 实现说明

- 使用 Ghost 原生搜索，不自建搜索索引
- 搜索触发器：导航栏搜索按钮
- 键盘可访问：`data-ghost-search` 属性，支持键盘操作
- 搜索范围：文章标题和正文（Ghost 默认索引字段）

## 已知限制

- Ghost 原生搜索基于 SQLite LIKE 查询，中文分词效果有限
- 长关键词可能因分词问题命中率降低
- 建议使用关键词或英文术语搜索
