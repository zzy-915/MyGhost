# Issue #1: 主题改造与自定义主题开发

**状态**: 已完成
**负责人**: 学生本人
**创建日期**: 2026-09-07
**关联 PR**: PR #1

## 用户故事

作为博客读者，我希望看到一个具有辨识度的自定义主题，能够在导航栏快速访问收藏功能，在文章页方便地收藏文章，以便后续阅读。

## 需求描述

1. 从 Ghost 内置 source 主题导出，创建自定义主题
2. 修改导航栏，添加"我的收藏"入口和收藏数量角标
3. 修改文章详情页，在分享按钮旁添加收藏按钮
4. 创建收藏列表页面模板，展示已收藏文章
5. 主题通过 gscan 兼容性检查
6. 主题在桌面和窄屏（移动端）均可用

## 验收条件

- [x] 导航栏显示"我的收藏"链接，带数字角标
- [x] 文章详情页显示"收藏"按钮，点击后状态变为"已收藏"
- [x] 收藏列表页面正常显示已收藏文章列表
- [x] 主题在桌面端（1280px）和窄屏（375px）均无溢出
- [x] 收藏功能键盘可操作（Tab 键可聚焦按钮）

## 实现方案

- 主题层实现，不修改 Ghost 核心
- 使用原生 JavaScript + localStorage 存储收藏数据
- Handlebars 模板修改：default.hbs、post.hbs、page.hbs、navigation.hbs
- 新增文件：bookmark.js、bookmark.css、page-bookmarks.hbs

## 风险与缓解

| 风险 | 缓解措施 |
|------|----------|
| 自定义主题激活失败 | 直接修改当前激活的 source 主题，确保功能生效 |
| 主题兼容性问题 | 运行 gscan 检查，记录警告是否影响功能 |
| 移动端布局溢出 | 使用响应式 CSS，测试 375px 宽度 |
