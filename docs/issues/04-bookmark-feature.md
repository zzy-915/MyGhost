# Issue #4: 自主功能 - 文章收藏/稍后阅读列表

**状态**: 已完成
**负责人**: 学生本人
**创建日期**: 2026-09-07
**关联 PR**: PR #1
**功能类型**: 非换色类自主扩展（实验拓展功能选项3）

## 用户故事

作为博客读者，我希望在浏览文章时能够一键收藏感兴趣的文章，并在专门的收藏列表页面查看和管理所有收藏，以便稍后阅读或快速回顾。

## 为什么选择这个功能

1. **用户价值明确**：解决"看到好文章想稍后读但找不到"的痛点
2. **非换色类**：不是简单的颜色/Logo/文案修改，而是完整的功能扩展
3. **技术边界清晰**：可以在主题层实现，不修改 Ghost 核心
4. **可测试**：有明确的验收条件和测试用例
5. **数据来源可控**：使用 localStorage，不依赖后端 API

## 需求描述

### 功能清单

1. **收藏按钮**：在文章详情页显示收藏按钮，点击切换收藏/取消收藏状态
2. **收藏入口**：在导航栏显示"我的收藏"链接，带收藏数量角标
3. **收藏列表页**：独立页面 `/bookmarks/`，展示所有已收藏文章
4. **移除收藏**：在收藏列表中可移除单篇文章
5. **本地存储**：使用 localStorage 存储收藏数据，无需登录
6. **状态同步**：收藏状态在页面间同步（角标数量、按钮状态）
7. **上限保护**：最多收藏 500 篇，防止 localStorage 溢出
8. **错误提示**：操作成功/失败有 toast 提示

### 数据结构

```javascript
// localStorage key: oss_blog_bookmarks
[
  {
    id: "post-id-1",
    title: "文章标题",
    url: "https://example.com/post/",
    excerpt: "文章摘要",
    image: "封面图URL",
    date: "2026-09-07",
    addedAt: 1694073600000 // 收藏时间戳
  }
]
```

## 验收条件

- [x] 文章详情页显示"收藏"按钮
- [x] 点击收藏按钮后，按钮变为"已收藏"状态
- [x] 导航栏收藏角标数量 +1
- [x] 再次点击按钮，取消收藏，角标数量 -1
- [x] 收藏列表页显示所有已收藏文章卡片
- [x] 收藏列表中每篇文章有"移除收藏"按钮
- [x] 点击移除按钮，文章从列表中消失
- [x] 空收藏列表显示友好提示（"还没有收藏任何文章"）
- [x] 刷新页面后收藏数据不丢失
- [x] 收藏操作有 toast 提示
- [x] 超过 500 篇时提示上限

## 实现方案

### 为什么放在主题层，而不是修改 Ghost 核心？

1. **升级边界**：Ghost 核心升级不会覆盖主题修改，收藏功能持续可用
2. **可移植性**：主题可以打包安装到其他 Ghost 实例
3. **低风险**：不涉及数据库迁移、后端 API 变更，出问题不影响核心功能
4. **符合实验要求**：实验明确推荐"在独立主题或伴随服务中做二次开发"

### 技术选型

| 组件 | 技术 | 理由 |
|------|------|------|
| 存储 | localStorage | 纯前端，无需后端，隐私友好 |
| 逻辑 | 原生 JavaScript | 无框架依赖，主题兼容性好 |
| 样式 | CSS | 与主题风格一致，响应式 |
| 模板 | Handlebars | Ghost 主题标准模板引擎 |

## 失败状态处理

- localStorage 不可用（隐私模式）：降级为内存存储，提示"当前浏览器不支持本地存储"
- 存储已满：提示"收藏数量已达上限，请移除部分文章"
- 数据格式错误：自动清空损坏数据，重新初始化
- 文章 URL 变化：收藏记录保留原 URL，点击可能404（已知限制）

## 隐私影响

- 收藏数据仅存储在用户浏览器 localStorage，不上传服务器
- 不收集用户行为数据
- 清除浏览器数据会同时清除收藏列表
- 不同浏览器/设备间收藏不共享（设计决策，简化实现）
